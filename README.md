# 台パンリバーシ<sup> 3D</sup>

台パンができるリバーシです。以下のリンクから遊べます。

https://reversi.syntck.com/

## ローカルでオンライン対戦を試す

1. シグナリングサーバーを起動
   - `cd server`
   - `npm install`
   - `npm start`
2. ゲームをブラウザで開く（2つのブラウザ/プロファイル）
3. タイトル画面の「オンライン対戦」から
   - ホスト: 「部屋を作成」
   - ゲスト: 「部屋に参加」→部屋一覧から参加

デフォルトのシグナリングURLは `ws://localhost:8787` です。
